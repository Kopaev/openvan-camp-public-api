# Contributing

Thanks for helping improve OpenVan.camp open data.

## Report wrong data

Fuel prices, visa rules, plate formats and other data come from official sources and are checked
regularly, but mistakes happen. [Open a "Wrong data" issue](../../issues/new?template=wrong-data.yml)
with the endpoint, the value you got, the correct value and a source link (a government site is best).

## Request an endpoint or MCP tool

[Open a "Feature request" issue](../../issues/new?template=feature-request.yml) and describe what you
want to build — the use case helps us decide what to add first.

## Code

This repository holds the public contract (`openapi.yaml`), the JavaScript SDK (`sdk/`), the MCP server
(`mcp-server/`) and examples (`examples/`). The API itself runs on openvan.camp and is not open source.
Pull requests to the SDK, MCP server and examples are welcome: keep changes small and describe how you
tested them.

## Questions

Use [Discussions](../../discussions) or write to hello@openvan.camp.
